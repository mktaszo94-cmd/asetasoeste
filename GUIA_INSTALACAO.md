# ASZO V2 — Fase 12.8.1 — Arquivo alinhado

## Objetivo
Alinhar o titulo e a barra expansivel do **Arquivo de eventos** com a secao **Proximos eventos**, mantendo os cartoes e respetivas imagens compactos. Sem modificacoes em HTML, JavaScript ou Pages CMS.

## Ficheiro a instalar
`assets/css/aszo-fase10-3.css` — ficheiro CSS completo, incluindo as alteracoes aprovadas da Fase 12.8.

## Instalacao passo a passo
1. Abre o GitHub Desktop e confirma o repositorio `asetasoeste`, ramo `desenvolvimento-v2`.
2. Nao alteres o ramo `main`.
3. Descarrega e extrai o ZIP desta atualizacao.
4. No GitHub Desktop, abre **Repository > Show in Explorer**.
5. Guarda uma copia do ficheiro atual `assets/css/aszo-fase10-3.css` fora do repositorio.
6. Copia o ficheiro do ZIP para `assets/css/aszo-fase10-3.css`, substituindo o atual.
7. No servidor local `http://localhost:8000/`, faz `Ctrl + F5`.
8. Confirma que o titulo do arquivo e o respetivo painel comecam na mesma margem esquerda que a secao de Proximos eventos; a barra expansivel ocupa a mesma largura de conteudo.
9. Abre o arquivo: os dois cartoes ficam compactos e lado a lado em desktop. Confirma setas, imagens e links, em PT e EN, e testa em telemovel.
10. Se tudo estiver correto, cria o commit `ASZO V2 - Fase 12.8.1 - Alinhamento do arquivo` e faz **Push origin** no ramo `desenvolvimento-v2`.

## Reverter
Restaura a copia do CSS ou utiliza **Discard Changes** no GitHub Desktop, antes de fazer o commit.
